# Sharped

Sharped is a browser-based editor for sharp-edged gradient backgrounds. Choose a colour preset or custom colour, drag the diagonal edges, regenerate a new composition, and export PNG, JPG, WebP, or SVG at social, Substack, Medium-friendly, story, or desktop sizes.

Open `index.html` in a browser to use the editor. It is a single static file and needs no build or server. Gradients are generated locally in the browser; no AI service or account is required.
